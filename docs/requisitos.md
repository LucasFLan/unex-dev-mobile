## Requisitos Funcionais

- [ ] O usuário deve ser capaz de se cadastrar no sistema.
- [ ] O usuário deve ser capaz de fazer login no sistema.
- [ ] O usuário deve ser capaz de fazer logout do sistema.
- [ ] O usuário deve ser capaz de alterar sua senha.
- [ ] O usuário deve ser capaz de alterar suas informações de perfil.
- [ ] O usuário deve ser capaz de cadastrar um novo anuncio.
- [ ] O usuário deve ser capaz de visualizar os anuncios.
- [ ] O usuário deve ser capaz de editar um anuncio.
- [ ] O usuário deve ser capaz de excluir um anuncio.
- [ ] O usuário deve ser capaz de avaliar um serviço.
- [ ] O usuário deve ser capaz de clonar um anuncio criado por ele mesmo.
- [ ] O usuário pode ativar e desativar seus anuncios.
- [ ] O usuário deve ter um perfil publico.

- [ ] O anuncio deve ter uma categoria.
- [ ] O anuncio pode ter imagens.
- [ ]  




## Requisitos Não Funcionais

- [ ] O sistema deve ser responsivo.
- [ ] O sistema deve ser acessível em dispositivos móveis.
- [ ] O sistema deve ser acessível em dispositivos tablet.
